# 꽃보다 예쁜 한미영 꽃백숙 다국어 메뉴판

QR로 접속하는 매장 메뉴 페이지입니다. 한국어, English, 中文, 日本語, Tiếng Việt, Français 6개 언어를 지원합니다.

## 구성

파일은 `index.html` 하나뿐입니다. 빌드 과정도 서버도 없습니다. 이 파일만 고치면 사이트가 바뀝니다.

## 메뉴 수정 방법

1. GitHub에서 `index.html`을 엽니다
2. 오른쪽 위 연필 아이콘을 누릅니다
3. 고칠 내용을 찾아 수정합니다
4. 아래 **Commit changes** 를 누릅니다
5. 1분 정도 지나면 사이트에 반영됩니다

### 가격 바꾸기

파일 아래쪽 `const DATA = [...]` 안에 메뉴가 들어 있습니다. 형식은 이렇습니다.

```
{"t":"item","x":"01.능이반계탕&찰밥(1인분)","p":"9,000"}
```

`"p"` 뒤의 숫자가 가격입니다. `9,000` 을 `10,000` 으로 바꾸면 됩니다.
**따옴표와 쉼표는 지우지 마세요.** 하나라도 빠지면 페이지가 안 뜹니다.

### 메뉴 이름 바꾸기

같은 줄의 `"x"` 뒤 내용이 메뉴 이름입니다.

### 줄 종류

| 표시 | 뜻 |
|---|---|
| `"t":"sec"` | 섹션 제목 |
| `"t":"item"` | 가격 있는 메뉴 |
| `"t":"sub"` | 하위 항목 (소주 브랜드 등) |
| `"t":"note"` | 안내 문구 |

### 언어별 위치

`"code":"ko"` 는 한국어, `"en"` 영어, `"zh"` 중국어, `"ja"` 일본어, `"vi"` 베트남어, `"fr"` 프랑스어입니다.
**가격을 바꾸면 6개 언어 모두 고쳐야 합니다.** 언어마다 따로 들어 있습니다.

## 수정 전에

고치기 전 파일을 복사해 두세요. 잘못 고쳐서 페이지가 안 뜨면, GitHub 저장소의 **History** 에서 이전 버전으로 되돌릴 수 있습니다.

## 다른 사람에게 넘기기

GitHub 저장소 **Settings > General > Transfer ownership** 에서 상대방 계정으로 옮기면 됩니다.
옮긴 뒤 상대방이 **Settings > Pages** 에서 배포가 켜져 있는지 확인하면 주소가 그대로 유지됩니다.

## 주소가 바뀌면

QR 코드를 다시 만들어야 합니다. 저장소 이름이나 소유자를 바꾸면 주소가 바뀌니 주의하세요.
